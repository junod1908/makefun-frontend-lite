make.fun lite is a bright, readable frontend for live bounties, rewards, leaderboards, and maker profiles. It uses ETag caching with a 45-second freshness window and lazily loaded views to keep navigation quick. Plain static files, no framework, and a tiny first load keep the focus on finding your next challenge.

## Run it

```sh
node serve.ts
```
Open http://localhost:8080
